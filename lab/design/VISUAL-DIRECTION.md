# Algorithm Lab 视觉设计方向 — 未来工业数字实验室

> 本文是三个实验室（APS / MAPF / AGV）前端重做的唯一视觉基准，由用户于 2026-10 批准。
> 概念图见 `concepts/`。参考图只定义美术方向，不限定最终布局。

## 一、整体定位

不是传统 SaaS 后台，也不是二维算法教学界面，而是**具有科学仪器气质的未来工业数字实验室**。
参考高端工业数字孪生、科幻空间计算界面、精密工业产品的视觉语言。
三个实验室统一设计语言，各自拥有不同核心视觉表现。

关键词：微缩工业沙盘 · 精密三维建模 · 深色电影级光影 · 发光轨迹与数据流 · 空间分层与信息悬浮 · 科学实验与工程探索。

## 二、3D 场景美术风格

1. **微缩工业沙盘**：等距（Isometric）或近等距三维透视；场景像摆放在实验室里的精密模型；
   建筑/货架/机器人/工作站适度抽象为简洁几何形体；介于精密工业模型与高级科幻概念设计之间。
   - 设备：精致倒角几何体；建筑与货架：明确体积感；地面：细密工程网格。
   - 环境光遮蔽（AO）表现接触关系；柔和环境光 + 局部光源营造纵深。
   - 适度使用透明材质、金属边框、发光元件。静止时也应像一幅精美工业概念作品。
2. **材质**：石墨灰、冷灰蓝、深金属色、少量浅灰；哑光金属/精密设备质感；
   重要设备与机器人带发光状态灯；次要建筑弱化颜色与对比度。
   不用写实纹理/照片材质/复杂环境贴图；高质量 Low Poly 工业模型，不廉价不卡通。

## 三、最重要的视觉元素：空间中的发光线条

1. **路径轨迹**：像精密仪器投射的空间轨迹，悬浮于沙盘上方。
   - 线条纤细，核心锐利清晰；核心外围极柔光晕；适当透明度。
   - 转弯自然过渡但保留真实算法路径几何含义。
   - 不同机器人不同识别色；当前执行路径明亮，历史变暗，未执行半透明/虚线；选中时更强发光。
   - 主色：冰蓝、青绿、紫罗兰、琥珀橙。**不要粗大霓虹灯管**——要精密、优雅、克制，
     像暗色环境中高精度光学仪器的细光线。
2. **发光节点**：路径关键节点用小型发光圆环/光点/空间标记
   （交汇点、机器人当前位置、重规划位置、取送点、事件位置）。内核光点 + 细线圆环 + 柔和外晕。
   **避免传统大号图钉。**
3. **动态轨迹**：已执行路径柔和光流/逐段点亮；重规划时旧路径渐暗、新路径以新光色展开。
   **所有动画必须对应真实离散时间步与引擎数据，不得暗示算法没有算出的连续运动。**

## 四、颜色、光影与画面气氛

- 背景：接近黑的深海军蓝（避免纯黑丢失细节）。
- 建筑：石墨灰、冷灰蓝。主算法路径：冰蓝/青色。次要路径：紫色/绿色。
- 任务与活动节点：琥珀橙。危险/冲突：珊瑚红。未激活：低对比冷灰。
- 电影级明暗层次，不牺牲数据可读性；发光集中于路径/关键节点/机器人/事件区；
  建筑地面面板克制。冷静工程感 + 视觉吸引力并存。

## 五、三个实验室的空间设计

- **MAPF 空间与路径实验室**：可旋转缩放的三维地图；栅格 → 有厚度的空间底板；
  障碍为低矮立体结构；机器人为精致抽象模型；多色发光轨迹交错；
  等距视角 ↔ 正交俯视平滑切换。像一件精密的空间计算仪器。
- **AGV 智能工业调度沙盘**：有纵深的微缩智能仓库/工厂（货架、设备、工作站、物流通道、移动机器人）；
  调度结果 = 三维动态物流网络；多机器人同时运行、任务空间关联、取送点、工作站状态与容量；
  路径变化的空间反馈；动态事件 → 局部光效/透明覆盖层；前后对比 → 双视图或同场景叠加。
  气质接近未来工厂数字指挥沙盘。
- **APS 生产排程实验室**：不强行走 3D 地图；生产系统抽象为立体工业生产单元
  + 精致二维时间轴/甘特图/资源关系图（3D 帮助理解系统，时间轴准确展示排程）。
  同样的深色材质、发光线条、信息层级；算法对比 = 并列空间实验窗口 + 统一指标图表。

## 六、技术方向

- **Three.js + React Three Fiber**：工业沙盘/空间模型/相机（等距）/机器人与设备渲染/
  三维路径、节点、空间标记/空间选择与事件高亮。
- **Canvas / SVG**：时间轴、甘特图、算法指标、二维分析图、大规模数据曲线。
- **React**：应用状态、实验控制、交互界面、运行历史与配置。
- **Rust / WASM**：真正的算法计算、调度与路径规划、独立验证。
- **红线**：Three.js 只是可视化层，不承担算法计算、不自行编造路径。
- **性能**：按需渲染、模型实例化、几何体复用、有限后期效果；提供轻量二维模式（低性能设备兜底）。

## 七、界面设计原则

空间场景是视觉主体；控制与信息面板以轻量悬浮形式围绕主视图，不长期堆满传统表单。
面板用细腻半透明深色材质、极细轮廓线、有限玻璃效果。
不用粗边框、高饱和渐变、巨型按钮、装饰性 HUD。
视觉科幻，交互保持专业工程软件的准确性。高级、精密、有辨识度，不堆特效。

## 八、最核心要求

**让复杂算法在视觉上成为一种可以探索、观察和理解的空间现象。**
